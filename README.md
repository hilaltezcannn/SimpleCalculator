# 🧮 Simple Calculator

İki sayı arasında dört işlem yapan basit bir hesap makinesi. UIKit ile geliştirilmiş bir iOS uygulamasıdır.

## Özellikler

- İki sayı girip **toplama, çıkarma, çarpma ve bölme** işlemleri yapma
- Sayı olmayan girişlerde uygulamanın çökmemesi için `if let` ile güvenli dönüştürme

## Teknolojiler

| | |
|---|---|
| Dil | Swift |
| Arayüz | UIKit, Storyboard |
| Kullanılanlar | `IBOutlet`, `IBAction`, `UITextField`, Optional binding |

## Çalıştırma

1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/hilaltezcannn/SimpleCalculator.git
   ```
2. `SimpleCalculator.xcodeproj` dosyasını Xcode ile açın.
3. Bir iPhone simülatörü seçip **▶︎ Run** ile çalıştırın.
